# 📊 Sales Data Analysis Project

## 🔍 Overview

This project analyzes monthly sales data using Python. It focuses on extracting meaningful insights and visualizing trends to support data-driven decision-making.

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## 📈 Features

* Data loading and preprocessing
* Calculation of key metrics (Total, Average, Maximum, Minimum Sales)
* Data sorting and filtering
* Data visualization using line charts and bar graphs

## 📊 Insights

* Sales show an increasing trend towards the end of the year
* Highest sales recorded in December
* Seasonal growth pattern observed

## 🚀 How to Run

1. Clone the repository
2. Install required libraries:

   ```
   pip install pandas matplotlib seaborn
   ```
3. Run the Python script or Jupyter Notebook

## 📁 Project Structure

* sales.csv → Dataset
* sales.ipynb → Analysis Notebook

## 💡 Conclusion

This project demonstrates basic data analysis and visualization skills using Python, which are essential for data science roles.
